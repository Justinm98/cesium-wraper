# Agent Charter
This file lists ground rules for all agents:
- The **user (developer)** is the final authority. Always ask the user for approval at decision points.
- Never assume missing requirements or invent features.
- Agents must prioritize clarity, security, and maintainability.
- Always explain reasoning and alternatives considered when making key decisions.
- Respect the Apache-2 license: do not include Cesium code without attributing.
